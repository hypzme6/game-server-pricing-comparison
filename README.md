## 租用前值得确认的几件事

下面这几件事比“哪家好”更容易影响实际体验，下单前花几分钟确认，能省掉后面的麻烦。

1. **活动价和续费价是否一致**。本文价格来自公开活动整理，低价通常对应活动周期，续费时是否同价要在页面确认。确认不了就先买短周期，别一次付一年。
2. **月流量超额怎么计费**。套餐含 2000GB 到 8000GB 月流量，超了是限速还是按量收费，页面或客服确认清楚。开服初期集中传模组时尤其容易碰到。
3. **节点选哪个**。玩家集中在南方选广州或上海，北方选北京，西南选成都；分布太散就选中间节点，或者让玩家先测延迟再定。
4. **系统盘够不够**。120GB 到 450GB 的 SSD 对大多数联机服够用，但地图备份、模组包会占空间，重要存档定期下载到本地。
5. **售后响应时间**。游戏服出问题多在晚上和周末，确认工单和在线支持的响应速度，比看宣传页上的“7×24”更实际。
